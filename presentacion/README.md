# PUCARÁ - Demo y presentación

Material de presentación del MVP de custodia institucional en Stellar Testnet.

- [Video demo v2 (MP4)](pucara-demo-v2.mp4)
- [Pitch deck NEA Tech (PDF)](pucara-pitch-nea-tech.pdf)

El deck incluye el problema, la solución y las cuatro características: independencia/autocustodia, seguridad/multisig, programabilidad/smart accounts y usabilidad/passkeys. La v2.0 propuesta contempla multisig 3 de 5, timelocks y Earn conectado a Blend; estas funciones se presentan como futuras.

Si GitHub no reproduce el MP4 en la página del archivo, usar **Download raw file** para abrirlo o descargarlo.
